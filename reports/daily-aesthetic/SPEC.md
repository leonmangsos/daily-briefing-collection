# 每日审美与创意情报｜产出规范（HTML 主格式）

## 目标
解决当前审美日报的 4 个核心问题：
1. 信息源单一（过度依赖 Godly / designboom）
2. 站点介绍平淡，缺少更深入的页面风格分析
3. 缺少稳定的页面样式总结结构
4. 没有为每个站点沉淀可复用的样式生成 prompt

---

## 一、后续信息源要求（必须多源）

### A. 网站 / 数字产品灵感源
至少从以下不同平台中组合获取，不得长期只用 Godly：
- Godly（网站精选）
- Awwwards
- SiteInspire
- Land-book
- Lapa Ninja
- One Page Love
- CSS Design Awards
- Httpster
- Minimal Gallery
- Browser London / god-tier studio blogs（如 Locomotive、Basic/Dept 等官网案例页）

### B. 视觉 / 空间 / 建筑 / 艺术源
至少从以下平台中组合获取，不得长期只用 designboom：
- designboom
- Dezeen
- ArchDaily
- It's Nice That
- Colossal
- Creative Boom
- The Brand Identity
- Wallpaper*
- IGNANT
- Dezeen Awards / AHEAD / Frame / Domus 等栏目

### C. 品牌与设计方法论补充源
当网站仅有视觉而缺少策略解读时，可补充：
- Studio 官网 About / Work / Process 页面
- Founder 采访
- Case study 页面
- 产品官网的 pricing / features / manifesto 页面

---

## 二、选题约束

### 1. 去重规则
- 默认回看最近 30 天历史日报
- 同一站点域名在 30 天内默认不得重复入选
- 除非属于“复盘专题 / 风格对比 / 改版分析”，否则禁止重复

### 2. 多样性规则
每天网站样本尽量覆盖不同类型：
- 创意工作室 / agency
- SaaS / AI 产品
- 消费电子 / 硬件品牌
- 个人品牌 / portfolio
- 电商 / DTC
- 文化 / 媒体 / 展览 / 艺术机构

### 3. 风格多样性
避免连续几天都选择同一类风格：
- 不要连续多天都选“黑底 + 3D + 沉浸式 agency”
- 尽量轮换：极简、编辑感、未来感、功能导向、人格化、装置感、生态材料感等

---

## 三、每个网站样本的固定输出结构

后续每个网站必须包含以下字段：

### 1. 基础信息
- 名称
- 链接
- 类型（agency / SaaS / hardware / personal / brand / editorial ...）
- 来源平台（如 Awwwards / SiteInspire / Godly / 官网直查）

### 2. 为什么值得看
要求：
- 不是泛泛夸“高级、好看、很强”
- 必须指出它在品牌表达、转化逻辑、叙事、布局或交互上的独特点

### 3. 页面样式总结（必须细）
至少拆成以下 8 个维度：
- **视觉基调**：冷静 / 热烈 / 奢华 / 编辑感 / 工业感 / 未来感 / 温暖等
- **配色方案**：主色、辅助色、背景策略、对比度特征
- **版式结构**：单栏 / 多栏 / 长滚动 / 卡片 / 分屏 / 杂志化编排 / 模块密度
- **字体系统**：无衬线 / 衬线 / 几何体 / 窄体 / 大字标题 / 字重对比等
- **首屏策略**：大标题、产品主视觉、视频、3D、口号、CTA 的关系
- **交互 / 动效语言**：滚动节奏、hover、过渡、镜头感、视差、切换方式
- **内容组织方式**：先讲品牌还是先讲产品，案例如何展开，是否强调 social proof
- **适用场景**：适合什么类型产品/品牌/内容页面参考

### 4. 可借鉴点
要求输出成 3~5 条可执行建议，不要空话。
例如：
- 首屏只保留一个价值主张 + 一个主视觉 + 一个 CTA
- 二屏开始用数据卡片做信任构建
- 把案例模块改成“问题-过程-结果”结构

### 5. 样式生成 Prompt（必须有）
每个站点都要沉淀一套可复用 prompt，至少包含：
- 适用对象（比如 AI SaaS 官网 / 工作室官网 / 个人作品集）
- 风格关键词
- 页面结构关键词
- 色彩 / 字体 / 动效要求
- 禁止项（避免抄袭感过强、避免过度复杂、避免信息噪音）

推荐格式：

```text
请生成一个【网站类型】首页设计方案，风格参考【站点名】的核心气质，但不要直接复制。
要求体现以下特征：
1. 视觉基调：...
2. 配色：...
3. 排版：...
4. 首屏结构：...
5. 动效语言：...
6. 内容模块：...
7. 适合品牌：...
避免：...
输出：高保真网页设计描述 + 页面结构说明 + 可直接用于生成设计稿/网页原型的提示词。
```

---

## 四、日报最终结构升级

以后“每日审美与创意情报”建议固定为：

1. 今日网站样本（2~3 条）
   - 每条都必须带页面样式总结 + prompt
2. 今日视觉 / 建筑 / 空间 / 艺术样本（1~2 条）
   - 要强调材料、结构、叙事或概念方法
3. 今日风格趋势判断（2~3 条）
4. 今日可直接复用的 Prompt 清单（汇总版）
5. 一句结论

---

## 五、质量要求

### 禁止写法
- “这个网站很高级、很有质感、值得学习” 这种空话
- 只写表层视觉，不解释结构和逻辑
- 只给链接，不做方法提炼
- 只谈审美，不沉淀成 prompt

### 鼓励写法
- 像设计总监 / 品牌顾问一样拆解页面
- 像体验负责人一样总结转化逻辑
- 像提示词工程师一样抽象成可复用风格 prompt

---

## 六、执行要求

后续每次生成审美日报时：
- 必须先检查最近 30 天是否重复
- 必须混合多个内容平台
- 每个网站必须产出“页面样式总结 + 样式生成 prompt”
- 正式交付统一为 HTML
