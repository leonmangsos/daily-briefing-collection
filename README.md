# Daily Briefing Collection

一个可持续更新的日报集合仓库，用于稳定沉淀与对外访问。

## 内容

- `reports/ai-edu-daily/`：AI 教育日报 Markdown
- `reports/daily-aesthetic/`：Daily Aesthetic / 设计审美日报 Markdown
- `outputs/daily-report/`：聚合导出的 HTML 与 Markdown 页面

## 更新方式

后续可持续将新日报追加到对应目录，并覆盖聚合输出文件，以保持链接稳定。

## 推荐稳定访问入口

- GitHub Repo

- 按日期索引页
